# E-commerce & Sales Dashboards

Interactive Excel dashboards for analyzing e-commerce and sales data. This project turns raw transaction data into clear visual insights that support faster, data-driven business decisions.

---

## Project Overview

This repository contains two macro-enabled Excel dashboards:

| File | Description |
|------|-------------|
| `EcommerceDashboard.xlsm` | Overview of e-commerce performance: orders, revenue, customers, and product/category trends |
| `SalesDashboard.xlsm` | Detailed sales analysis: sales trends over time, top products, regions, and key performance indicators |

---

## 1. E-commerce Dashboard (`EcommerceDashboard.xlsm`)

A high-level view of how the online store is performing.

**What it shows**
- Total orders, revenue, and customers
- Best-selling products and categories
- Order and revenue trends over time
- Customer and order distribution

---

## 2. Sales Dashboard (`SalesDashboard.xlsm`)

A detailed, interactive dashboard focused on sales performance. It helps managers quickly see what is selling, where, and when.

### Key Metrics (KPIs)
- Total Sales / Revenue
- Total Profit
- Total Quantity Sold
- Number of Orders
- Average Order Value

### Visualizations
- **Sales trend:** monthly / yearly sales performance (line chart)
- **Top products:** best-selling products and categories (bar chart)
- **Regional analysis:** sales by region, state, or city
- **Category share:** contribution of each category to total sales (pie / donut chart)
- **Customer segments:** sales by customer type

### Interactivity
- **Slicers** to filter by year, month, region, category, and more
- **Pivot tables and pivot charts** that update dynamically
- **Macros (VBA)** to refresh data and automate dashboard updates

### Business Questions It Answers
- Which products and categories generate the most revenue and profit?
- Which regions perform best, and which need attention?
- How do sales change month over month and year over year?
- Who are the most valuable customer segments?

## How to Use

1. **Clone or download** the repository:
   ```bash
   git clone https://github.com/Aishwarya-168/Ecommerce1.git
   ```
2. Open either `.xlsm` file in **Microsoft Excel**.
3. Click **Enable Content / Enable Macros** when prompted.
4. Use the slicers and filters to explore the data.

> Macro-enabled files (`.xlsm`) need desktop Excel. They will not run correctly in the browser version.
